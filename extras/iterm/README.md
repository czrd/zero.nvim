# zero.nvim — iTerm2

Two theme files: `zero-dark.itermcolors` and `zero-light.itermcolors`.

## Setup

1. Open iTerm2 → **Settings** → **Profiles** → **Colors**
2. Click **Color Presets…** → **Import…**
3. Select `zero-dark.itermcolors` (or `zero-light.itermcolors`)
4. Click **Color Presets…** again and select **zero-dark** (or **zero-light**)

## Switching modes

Repeat step 4, selecting the other preset. Each profile can have its own preset,
so you can create a "zero-dark" profile and a "zero-light" profile for quick switching.
